\# Mobile Development II



Projeto acadêmico desenvolvido na disciplina \*\*Desenvolvimento Mobile II\*\*, utilizando Android Studio e Kotlin.



O repositório acompanha as atividades e implementações realizadas durante o semestre, seguindo os conteúdos e orientações apresentados em aula.



\## Funcionalidades



\- Cálculo do combustível mais vantajoso entre etanol e gasolina

\- Regra de comparação baseada na relação entre os preços dos combustíveis

\- Limpeza dos campos e do resultado

\- Navegação entre telas

\- Exibição de uma lista de veículos

\- Uso de ViewModel e LiveData para gerenciamento de dados



\## Tecnologias



\- Kotlin

\- Android Studio

\- XML

\- Android Views

\- View Binding

\- ViewModel

\- LiveData

\- Gradle
